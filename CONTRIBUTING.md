# Contributing Guidelines

Thank you for contributing to `cad-mesh-analyzer`!

## How to Contribute

1. **Fork & Clone:** Fork the repository and clone it locally.
2. **Branching:** Create a feature branch using `feat/description` or `fix/description`.
3. **Running Tests:** Run unit tests with `python -m unittest discover -s tests`.
4. **Pull Requests:** Submit a PR targeting `main`. Ensure all CI checks pass.
